# Security policy

Please don't report security problems in public issues, pull requests or discussions.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting: open the affected repository, go to the **Security** tab and choose **Report a vulnerability**. Include what you found, how to reproduce it, and the affected version or commit.

We'll acknowledge your report, keep you updated while we work on a fix, and credit you in the advisory if you'd like. Please give us a reasonable time to release a fix before disclosing details publicly.

## Supported versions

Fixes go into the latest release of each project. Ten98 apps are in active development, so upgrade to the latest release to receive security fixes.

A repository's own SECURITY.md, where present, adds details specific to that project.
