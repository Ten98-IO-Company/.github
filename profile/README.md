# Ten98

Open-source, self-hostable tools for marketing teams.

| Project | What it does |
|---|---|
| [Campaign](https://github.com/Ten98-IO-Company/ten98-campaign) | Plan, approve and publish social, advertising, email, SMS and WhatsApp campaigns, with a unified inbox. |
| [Discover](https://github.com/Ten98-IO-Company/ten98-discover) | SEO, AI-search visibility and web analytics. |
| [Design System](https://github.com/Ten98-IO-Company/ten98-design-system) | The shared React components and patterns behind Ten98 apps. |
| [Code System](https://github.com/Ten98-IO-Company/ten98-code-system) | Shared runtime code and standards for Ten98 apps. |

All projects are MIT-licensed. Each repository's wiki has setup guides, its Discussions tab is the place for questions and ideas, and the [Ten98 project board](https://github.com/orgs/Ten98-IO-Company/projects/1) shows what we're working on.

Found a security problem? See our [security policy](https://github.com/Ten98-IO-Company/.github/blob/main/SECURITY.md).
